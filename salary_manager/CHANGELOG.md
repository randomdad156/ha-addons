# Changelog

## 1.0.1 (2026-08-17)

- Privacy cleanup: the app's built-in starting data (used only when no saved data exists) now contains generic placeholder values instead of example personal data. Your own saved data is unaffected.

## 1.0.0 (2026-08-17)

- First release as a Home Assistant add-on: data stored on Home Assistant (salary-manager-data.json) and shared across devices, with 14 daily server-side backups, plus Export/Import buttons.
