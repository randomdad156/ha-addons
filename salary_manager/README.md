# Salary Manager

Salary Manager served from Home Assistant, with data stored on your HA machine and
shared across every device (behind HA login / Nabu Casa). Ingress-based, no ports.

Data: `/data/salary-manager-data.json` inside the add-on, plus 14 daily backups in `/data/backups`.
Load your existing data once via the app's Import, then it lives on Home Assistant.
